# Support

Thanks for using the Cellucid community annotation layout.

## Getting help

- Documentation: https://cellucid.readthedocs.io/en/latest/user_guide/web_app/j_community_annotation/index.html
- Issues about the layout itself — the three schemas, the validator, or the
  workflow: https://github.com/theislab/cellucid-annotation/issues
- Issues about how Cellucid signs in, pulls, compiles consensus, or publishes:
  https://github.com/theislab/cellucid/issues
- If `python scripts/validate_user_files.py` rejects a file, its message names
  the exact document and rule. Quote both when opening an issue.
- For security issues, see `SECURITY.md`.

## Data & privacy

An annotation repository is as public as its GitHub visibility. Don’t store
expression matrices, embeddings, clinical identifiers, source data, access
tokens, or private keys here, and don’t paste them into issues. The README’s
privacy section is the complete list.

## Code of Conduct

All project spaces are covered by `CODE_OF_CONDUCT.md`.
